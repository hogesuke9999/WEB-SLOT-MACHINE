# WEBスロットマシン（マルチデバイスリアルタイム同期システム）

親端末（操作画面）での操作・テキスト設定を、WebSocket（Socket.io）を介して複数の子端末（閲覧専用ディスプレイ）にリアルタイムで配信・同期表示するWEBスロットマシンシステムです。

サーバー上に展開することで、親・子ともに**WEBブラウザを開くだけで利用可能**（特別なアプリのインストールは一切不要）です。

---

## 🌟 主な機能・特徴

- **マルチデバイス・リアルタイム同期**
  - 親画面1台の操作（スタート／個別ストップ）が、親の承認済み子画面にリアルタイムで同期されます。
- **QRコードで簡単参加**
  - 親画面上に接続用QRコードが動的生成されます。読み取ると接続IDが入力されますが、名前を入力して親が承認するまでスロット情報は表示されません。
- **安心のアクセス制御**
  - **子画面（閲覧）**: 表示名と4桁IDで接続をリクエストし、親画面で承認された端末だけがその親のスロットを閲覧できます。
  - 接続IDは接続先の指定にのみ使われ、IDだけでは閲覧できません。ID入力には回数制限があり、保留中リクエストは2分で失効します。
- **柔軟な操作性**
  - **一括スタート** ＋ **レーン数に応じた個別ストップ（1つ目〜3つ目）**に対応。
- **演出・効果音（SE）**
  - リール回転音・停止音・確定ファンファーレ（Web Audio APIによる自動生成）。
  - 全リール停止時の結果ポップアップ拡大 ＆ **紙吹雪（Confetti）**アニメーション。
- **自動整形・テキスト長対応**
  - テキストが全角8文字を超える場合は、自動的に省略表示（`…`）されレイアウト崩れを防止。
- **SQLite データベース連動**
  - 入力テキストの「プリセット保存・呼び出し機能」。
  - 過去の当選・抽選履歴の記録 ＆ CSVダウンロード機能。

## 🚀 動作環境・動作要件

* **Node.js**: v18.0.0 以上推奨
* **npm**: v9.0.0 以上推奨
* **対応ブラウザ**:
* Google Chrome, Apple Safari, Microsoft Edge, Mozilla Firefox (最新版)
* iOS / iPadOS Safari, Android Chrome (標準カメラからのQR読み取り対応)

## 🛠️ ローカル環境での起動手順

### 1. リポジトリの準備・依存関係のインストール

```bash
# パッケージのインストール
npm install

```

### 2. サーバーの起動

```bash
# 開発・実行
npm start

```

起動後、コンソールに `Server running on http://localhost:3000` と表示されれば完了です。

### 3. ブラウザでアクセス

1. **親画面（操作パネル）**:
* URL: `http://localhost:3000/parent.html`
* 初期パスワード: `admin123`


2. **子画面（閲覧専用ディスプレイ）**:
* URL: `http://localhost:3000/child.html`
* または、親画面に表示される**QRコード**をスマホ・タブレット等で読み取って接続。

## ⚙️ 環境変数の設定 (オプション)

待受アドレス、ポート番号、管理者パスワードは環境変数で設定できます。`HOST` を省略した場合は `127.0.0.1` で待ち受けるため、サーバーを実行している端末からのみアクセスできます。他の端末からアクセスする場合は、`HOST` に `0.0.0.0` を指定して全ネットワークインターフェースで待ち受け、アクセス先にはサーバー端末のIPアドレスを使用してください。必要に応じてファイアウォールでポートへの接続を許可してください。

```bash
# 例: Linux / macOS（全アドレスで待ち受け、ポート8080を使用）
HOST=0.0.0.0 PORT=8080 ADMIN_PASSWORD="YourSecurePassword" npm start

# 例: Windows（PowerShell、全アドレスで待ち受け）
$env:HOST="0.0.0.0"; $env:PORT="8080"; $env:ADMIN_PASSWORD="YourSecurePassword"; npm start

# 例: Windows（PowerShell、既定の127.0.0.1で待ち受け）
$env:HOST="127.0.0.1"; npm start

```

## 📖 使い方

### 1. 初開設定（親画面）

1. `http://localhost:3000/parent.html` にアクセスし、パスワードを入力してログインします。
2. 「リールテキスト設定」エリアに、1つ目・2つ目・3つ目のレーンで回転させたい文字列を**改行区切り**で入力します。レーンが2つの場合は、1つ目・2つ目のみを使用します。
3. 「設定を適用＆配信」ボタンを押すと、すべての接続中子画面にデータが送信されます。
4. 設定内容は「プリセット保存」から名前を付けて保存しておくことが可能です。

### 2. 子画面の接続

1. 子画面で表示名と親画面の4桁IDを入力します。QRコードから開いた場合、IDは自動入力されます。
2. 「接続をリクエスト」を押すと、親画面に表示名が通知されます。
3. 親が名前を確認して「接続を承認」を押すと、子画面にスロットが表示されます。拒否または2分経過後は接続されません。
4. 接続後、画面中央の **「画面をタップして開始」** を1回タップすると効果音が有効になります。

### 3. スロットの開始・停止

1. **スタート**: 親画面の「スタート (一括回転)」ボタンを押すと、全端末の子画面が一斉に回転し始めます。
2. **ストップ**: 親画面の「1つ目 ストップ」「2つ目 ストップ」「3つ目 ストップ」ボタンを任意のタイミングで個別に押します（レーンが2つの場合は2つ目まで表示されます）。
3. **結果確定**: 設定したすべてのレーンが停止すると、子画面中央に結果が大きくポップアップし、紙吹雪とファンファーレが流れます。結果は自動的にSQLiteデータベースの履歴に保存されます。
