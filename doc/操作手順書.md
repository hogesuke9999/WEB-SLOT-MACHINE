# WEBスロットマシン 操作手順書

親画面から抽選を操作し、承認した子画面に結果を表示するための手順書です。

## 1. 利用前の準備

- サーバーが起動していることを確認します。起動方法は [README.md](../README.md) の「ローカル環境での起動手順」を参照してください。
- 親画面を操作する端末と、結果を表示する子端末（スマートフォン、タブレット、PCなど）を用意します。
- それぞれの端末で、管理者から案内されたサーバーのURLを開きます。ローカル環境の場合は、親画面が `http://localhost:3000/parent.html`、子画面が `http://localhost:3000/child.html` です。別端末から利用する場合は、`localhost` ではなく、その端末からアクセスできるサーバーのURLを使用してください。

## 2. 親画面を登録する

1. 親画面を開きます。
2. 必要に応じて「名前（任意）」に親の名前を入力します。
3. 抽選に使うリール数を「1個」「2個」「3個」から選びます。選んだ数だけ結果欄とストップ操作が表示されます。
4. 「登録してIDを発行」を押します。
5. 発行された4桁IDと有効期限を確認します。子端末の接続に使うため、IDを参加者に伝えるか、画面上のQRコードを使います。

![親セッション登録画面](スクリーンショット%202026-11-01%20204746.png)

登録後は、親画面に子画面用QRコード、接続状況、スロットプレビュー、操作ボタンが表示されます。画面上部には親の名前とID、接続中の子端末数が表示されます。

![親画面と接続情報](スクリーンショット%202026-11-01%20204903.png)

## 3. 子画面を接続・承認する

### 子端末から接続をリクエストする

1. 子端末で子画面を開きます。親画面のQRコードを読み取ると、接続IDが自動入力された状態で開きます。手入力の場合は、親画面に表示された4桁IDを入力します。
2. 「表示する名前」に参加者を識別できる名前を入力します。
3. 「接続をリクエスト」を押し、親画面での承認を待ちます。

![子画面で名前とIDを入力](スクリーンショット%202026-11-01%20205133.png)

### 親画面で接続を承認する

1. 親画面の「子画面の接続状況」に表示された承認待ちの名前を確認します。
2. 相手を確認できた場合は「接続を承認」を押します。接続させない場合は「拒否」を押します。
3. 承認後、名前が「承認済み」に表示され、接続端末数が更新されたことを確認します。

表示名だけでは相手本人かどうかを確認できません。参加者と照合してから承認してください。接続リクエストは2分で失効するため、間に合わなかった場合は子端末から再度リクエストします。

![親画面で承認待ちの名前を確認](スクリーンショット%202026-11-01%20205147.png)

![承認済みの子画面を確認](スクリーンショット%202026-11-01%20205154.png)

承認された子画面にはスロットが表示されます。初回は子画面をタップして音声を有効にします。音声が不要な場合も、スロット表示自体は利用できます。

## 4. 抽選内容と確率を設定する

親画面の「確率設定エディタ」で、各リールに表示する項目と当選確率を設定します。

1. 各項目の名前と割合（%）を入力します。
2. 項目を増やすときは、そのリールの「+追加」を押します。不要な項目は「削除」で取り除きます。
3. 使用するすべてのリールで、割合の合計がそれぞれ100%になるようにします。割合の合計が100%でない場合は設定を適用できません。
4. 「設定を適用＆配信」を押します。適用内容が表示されたら、内容を確認して閉じます。

設定は承認済みの子画面にも配信されます。抽選中は設定を変更できません。表示文字が長い場合は、画面上で省略されることがあります。

![確率設定エディタ](スクリーンショット%202026-11-01%20204924.png)

## 5. 抽選を実行する

1. 親画面の「スタート (一括回転)」を押します。承認済みの子画面と親画面のプレビューで、選択したリールが回転します。
2. 止めたいタイミングで「1つ目 ストップ」から順に、各リールのストップボタンを押します。停止する順番やタイミングは任意です。
3. 使用中のすべてのリールを停止すると結果が確定します。子画面には結果が大きく表示され、演出が再生されます。
4. もう一度抽選する場合は、リールがすべて停止したことを確認してから再度「スタート (一括回転)」を押します。

![子画面に表示される抽選結果](スクリーンショット%202026-11-01%20205257.png)

## 6. 当選履歴を確認・保存する

- 抽選結果は親画面下部の「当選履歴」に記録されます。日時と各リールの結果を確認してください。
- 履歴をファイルに保存する場合は、「CSVダウンロード」を押します。

![当選履歴とCSVダウンロード](スクリーンショット%202026-11-01%20205331.png)

## 7. 終了・注意事項

- 親画面の「ログアウト」を押すと、親セッションが終了し、接続中の子画面も切断されます。続けて利用する場合は、親画面を登録し直してください。
- 親セッションの有効期間は発行から24時間です。有効期限は親画面に表示されます。期限切れになった場合は、新しい親セッションを登録し、子端末を再接続してください。
- 承認待ちの接続リクエストは2分で失効します。子画面で再度「接続をリクエスト」を押してください。
- 子画面に結果が表示されない場合は、親画面で接続端末数と「承認済み」の一覧を確認します。未承認の場合は承認し、承認済みでも接続されていない場合は子画面を再読み込みして再接続してください。
